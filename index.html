// Core Utilities

Platform Package Bridge

Intelligently maps pipsqueak install <pkg> straight to your host's native manager: Homebrew (macOS), Advanced Package Tool (Debian/Ubuntu), or Pacman/AUR wrappers (Arch Linux). Includes strict safety checks to prevent binary command collisions.

Vibe Personality Matrix

Hot-swap execution wording layers instantly straight from your active prompt via pipsqueak flavor <type>. Choose between CHILL for minimal human-first telemetry, DEV for cold data metrics, or CHAOS for unpredictable roommate responses.

Secure Local Scratchpad

A completely offline, rapid-access markdown text engine isolated directly inside your terminal session path. Run pipsqueak note add to instantly append ideas or drop into your native configurations using pipsqueak note edit.

Ambient Diagnostics

Scans background system metrics and error paths (via journalctl hooks) to cross-match structural execution crashes into clean, actionable solutions without any external network tracking or cloud lookups.

// Guarding Your Shell

Pipsqueak acts as a silent, context-aware guardian layer. If you run into severe system syntax execution script errors or permission deadlocks, the protective posture modes catch it, block execution, and keep your workspace intact.
